# 🪶 WeekBrowser

**WeekBrowser** — це ультралегкий веб-браузер для Android. Він створений для тих, кому потрібна максимальна швидкість, тотальна кастомізація та повага до ресурсів пристрою. 

Він запитує мінімум дозволів (і то, якщо не дозволите — Всесвіт від цього не схлопнеться назад в сингулярність), має простий(?) та зрозумілий(???) інтерфейс, оскільки фокус тут на швидкодію (чисто по-пацанськи, без зайвого сміття).

## ✨ Особливості та кілер-фічі

- 🪶 **Екстремально малий розмір** — APK-файл важить менш як **600 КіБ**, а встановлена програма роздувається максимум до **1.5 МіБ**. Для порівняння: найближчі "міні-конкуренти" стартують від 18 МіБ. 
- 🌐 **На базі системного WebView** — використовує перевірений двигун Android. Жодних важких фонових процесів рендерингу в самому додатку.
- 🕒 **Розумна історія** — швидке очищення в один клік або свайпом по кнопці (для видалення лише останніх записів). Будете не один раз "дякую" казати, коли забудете ввімкнути режим інкогніто :)
- 📑 **Прокачаний головний екран** — закладки повністю під вашим контролем. Можна створювати кастомні пошукові поля, HTML-віджети та ховати це все в папки.
- 🖥️ **Віконний режим та мультипосилання** — відкривайте кілька сайтів одночасно на одному екрані. Ба більше, ви можете зберегти всю робочу сесію у **мультипосилання** (у ньому зашифровані URL-адреси, позиції та розміри всіх вікон) і поділитися ним.
- 🎯 **Унікальний UX (Менеджер позицій)** — можна глобально зберегти 3 позиції прокрутки сайту, щоб браузер автоматично повертав вас до потрібного місця на сторінці. Також є швидкий експорт усіх відкритих вкладок у зручний текстовий звіт в один клік.
- 🎨 **Глобальні скіни** — тут не просто примусова темна тема. Сайти реально адаптуються під обраний скін браузера (якщо тільки ви не додали сайт у винятки).

- 🔒 **Безжалісний антифлуд та блокування реклами** — блокує банери й відеорекламу, підставляючи замість них невидиму псевдорекламу (щоб "вкрай бідні" сайти не благали вимкнути AdBlock). 
  **Вас теж бісить**, коли ви випадково клацаєте по банеру в якійсь грі, і вас перекидає на клятий рекламний сайт? На слабкому смартфоні цей маневр коштує 40 років життя і тонни нервів. **Рішення є:** WeekBrowser перевіряє посилання, і якщо воно веде в якусь рекламну парашу — додаток просто сам себе закриває. Просте рішення, до якого чомусь ніхто раніше не додумався. Колеги-розробники, можете сміливо брати ідею, я не жадібний))
- 🧠 **Живчик для ретро-девайсів** — підтримує Android, починаючи з версії **5.0 (Lollipop)**. Ідеальний варіант, щоб подарувати старому планшету друге життя.

## 🛠 Збірка та розробка

WeekBrowser написано на Java для Android з використанням середовища Sketchware Pro.

Щоб зібрати програму власноруч:
1. Клонуйте цей репозиторій або завантажте .swb з Releases.
2. Відкрийте проект у Sketchware Pro (якщо .swb) або сумісному з Android Studio середовищі.
3. Скомпілюйте та встановіть на свій пристрій.
